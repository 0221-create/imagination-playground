# 두근두근 상상 놀이터

초등 1학년 통합교과 「상상」의 두 주제를 위한 자체 제작 수업 웹페이지입니다.

## GitHub Pages

수업 웹페이지 주소: [https://0221-create.github.io/imagination-playground/](https://0221-create.github.io/imagination-playground/)

## 활동

- 여기저기에서 본다면: 앞·옆·위 관찰, 6문제 방향 찾기, 선과 스티커로 상상 그림 만들기, PNG 저장
- 새로운 동물이 나타난다면: 동물 부품 조합, 색과 크기 조절, 소개 카드 작성, PNG 저장 및 인쇄/PDF
- 주제별 40분 수업, 학생 활동지와 교사용 안내 PDF

로그인이나 API 키 없이 사용합니다. 작품은 화면에만 보관되므로 닫기 전에 저장하세요. 학생 작품을 서버로 전송하지 않습니다. 음성 안내는 브라우저의 한국어 음성 지원에 따라 다릅니다.
